## 📌 프로젝트 소개

**Throw**는 사용자가 주변 쓰레기통 위치를 쉽게 확인하고,  
매장이 직접 쓰레기통 정보를 등록하여 사용자에게 안내할 수 있는 Android 앱입니다.

사용자는 지도 기반으로 주변 매장을 확인하고,  
매장은 쓰레기통 종류와 위치 정보를 등록하여 친환경 활동에 참여할 수 있습니다.
